Ayah a Day - setup
==================

The app is a small website made of these files. No account and no sign-in.

1. Put it online (free, about 2 minutes)
   - Go to https://app.netlify.com/drop
   - Drag this whole "ayah-a-day-app" folder onto the page.
   - You get a web address like https://something.netlify.app
   (GitHub Pages or any other web host works too.)

2. Install it on each device
   - iPhone / iPad: open the address in Safari > Share > Add to Home Screen.
   - PC / Mac: open it in Chrome or Edge > click the install icon in the address bar.
   - Android: open it in Chrome > menu > Install app.

3. Learners
   - Each person adds their own name on the first screen.
   - Several people can share one device, and each one has separate progress.

4. Moving progress between devices
   - Progress > Backup and transfer > Save backup file  (or Copy transfer code)
   - On the other device: Restore from a backup file  (or Paste a transfer code)
   - Recordings stay on the device where they were made.

Offline use on a PC without hosting: double-click index.html. Progress saves in that
browser, but the microphone and "install as app" need the online address from step 1.
